Диагностика разрыва

Чтение никогда не удаляет данные автоматически. Для непрозрачного разрыва укажите отдельно известный предыдущий operational head.

Экспериментальная схема: AES-key = SHA-256(plaintext), поэтому конфиденциальность предсказуемых данных не гарантирована. Перезапись занятого successor slot возможна только явно и может сделать старый поздний head неполным; старый хвост автоматически не удаляется. Для provenance нужен независимо сохранённый доверенный H и доверенный verifier.
